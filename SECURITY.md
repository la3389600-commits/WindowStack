# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include affected versions, reproduction steps, impact, and any suggested mitigation.

Please do not open a public issue containing exploit details. Maintainers will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.

WindowStack requires macOS Accessibility permission to manage windows. This permission is expected behavior and should not be reported as a vulnerability by itself.
